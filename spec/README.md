演示数据追加确认：允许用根目录 Python 文件在非生产环境幂等创建固定英文演示单据，覆盖双方分别等待、自动一致和数量差异。该入口明确绕过真实 OCR/模型，仅用于体验已验收的工作台流程；不得伪装成模型准确率或 TapTouch 生产接入。

真实抽取修正：MinerU 未提取供应商名称时，结构化模型不得把 `TAX INVOICE`、`INVOICE` 或 `GOODS RECEIVED NOTE` 等单据标题写成供应商名称。供应商名称可以未知，同时保留有原文依据的 ABN 和地址；页面提示人工校正，不影响基于相同 ABN 的保守候选排序。

本 Spec 作者固定的实施选择：PostgreSQL 持久化编排；3 秒后台轮询；新 `/api/workspace` 契约；旧工作流冻结而非删除；整张收货单独占确认、不做部分数量分配；保守匹配、一次人工确认；基于工作区新增不可变快照，不把机器预览伪装成旧批准版本。这些选择作为已授权开发基线生效，执行 Agent 不得更换。

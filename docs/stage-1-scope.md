# 阶段 1：结构化比对闭环

## 目标

先证明业务比对逻辑成立，再接入 OCR 和大模型。阶段 1 输入为人工准备或模型抽取后的标准 JSON，输出逐行差异与人工复核标记。

## 业务边界

- 一张 Invoice 可以对应一张或多张 Receive Note。
- 优先按 SKU 匹配；缺少 SKU 时按标准化商品描述匹配。
- 多张 Receive Note 中相同商品会先汇总数量和金额。
- 检查数量、加权单价和总金额差异。
- PO 号或币种不一致时必须进入人工复核。
- 模型只负责文档字段抽取与候选匹配，不直接决定财务结果。

## 后续阶段

原件上传、MinIO 保存和 PostgreSQL 任务记录已经完成。下一步为：

1. 建立 OCR/视觉模型抽取适配层，同时评估公共 API 与本地部署。

4. 增加差异审核、审批记录和 CSV/Excel 导出。

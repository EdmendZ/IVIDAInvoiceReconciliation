# ADR 0005：PostgreSQL 与 MinIO 分工存储

- 状态：Accepted
- 日期：2026-07-31

## 背景

原始 PDF/图片和 MinerU ZIP 体积大；任务、版本、动作和核对结果需要关系查询、
事务和约束。

## 决策

- MinIO 保存原件与二进制解析产物；
- PostgreSQL 保存状态、关系、JSON 快照和审计记录；
- 不引入 MongoDB/Milvus 作为本链路依赖。

## 结果

业务事务保持在 PostgreSQL，对象存储避免数据库膨胀。代价是存在跨存储操作，
上传采用“对象写入后数据库失败则补偿删除”，尚不是分布式事务。

## 重新评估条件

对象规模、保留策略、跨区域灾备或内容检索需求变化时，重新评估生命周期、
加密、事件通知和索引方案。

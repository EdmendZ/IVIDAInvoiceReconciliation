# ADR 0004：最终差异使用确定性规则

- 状态：Accepted
- 日期：2026-07-31

## 背景

LLM 擅长理解不同模板，但金额与数量判断要求可重复、可测试和可审计。

## 决策

LLM 只归一化字段。商品聚合、数量、加权单价、金额差和容差分类由纯 Python
函数完成。

## 结果

优点：

- 相同输入得到相同输出；
- 无数据库即可单元测试；
- 每条差异有数值和原因；
- 不受 Prompt 温度和模型升级影响。

代价：

- 商品同义词和 SKU 变化仍需主数据/候选匹配；
- 规则变化需要版本化和回归测试；
- 复杂商业合同可能超出固定容差。

## 重新评估条件

可使用 embedding/LLM 辅助产生商品候选，但最终金额判定仍保留确定性门禁。

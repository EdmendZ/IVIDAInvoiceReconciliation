# ADR 0003：只有人工批准不可变版本能核对

- 状态：Accepted
- 日期：2026-07-31

## 背景

模型输出可能合法但错误。若直接对 Draft 核对，后续人工修改会让历史结果无法
解释；若批准版本可覆盖，已保存核对结果的含义会变化。

## 决策

- 模型只生成 DocumentDraft；
- 人工操作创建 DocumentVersion；
- 每次编辑/重分类创建新版本；
- 批准时服务端重新校验；
- Approved Version 不可修改；
- 核对只引用 Approved Version ID。

## 结果

得到可追踪的机器输出、人工修改、批准主体和核对输入。代价是表和流程更多，
用户不能直接覆盖错误。

## 已知边界

当前是单人批准，不是四眼审批。Version 编号采用最大值加一和唯一约束，在高
并发审核下可能冲突；生产环境需要锁、序列或冲突重试。
